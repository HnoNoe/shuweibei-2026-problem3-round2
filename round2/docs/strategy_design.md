# 第 6 步策略设计文档：两阶段随机调度引擎

> 先读这个再读代码。本文档是 `strategy.py` 的说明书：每个设计决策给出公式、
> 文献锚点（编号对应 `references.md`）、它防的失败模式。

## 0. 架构总览

```
reset(trial 配置)                      decide(snapshot) 每决策点
┌─────────────────────┐              ┌──────────────────────────────────┐
│ 离线层：先验序列生成  │   在线层：   │ 1. 更新器吃完成/删失反馈(第5步通道)│
│  · 期望时长确定性扫描 │  跟随序列 + │ 2. 候选集 = 已释放 ∧ 前序完 ∧ 未执行│
│  · L5: G 情景局部搜索 │  触发式修正 │ 3. L1 打分（ATC / 序列位置）        │
│    改进该序列         │  （重打分、  │ 4. L2 截断防护（放松链 q95→q75→均值）│
└─────────────────────┘   守卫、前瞻）│ 5. L3 预算取舍（价值密度）          │
                                     │ 6. L4 rollout：top-m 候选 × K 情景 │
                                     │    CRN 同步模拟余程 → 期望加权准时率│
                                     │ 7. 输出 execute(b=0.2) / wait / stop│
                                     └──────────────────────────────────┘
```

题面允许这个架构的根据：**release/due/weight/zone/前序全部公开**（snapshot 明文），
唯一随机量是时长 d 与映射 (α,β)。所以这是"先验优化 + 反应式重排"的两阶段随机
调度（文献 42 Elaswad 2026 同构：手术时长也是对数正态，先定序列再现场反应；
文献 43 的多阶段 DP 表述）。离线层不是奢侈品，是题面信息结构送的。

## 1. 时长估计接口（全部经第 5 步的三口）

- 底账：`DurationModel.from_gofit()`，family → (μ, σ)，冻结。
- trial 内更新：每个策略实例持有自己的 `MixedLikelihoodUpdater`；
  每决策点从 snapshot 反推反馈：
  - `j ∈ completed`：`d = completion_time[j] − s_j`，s_j = 动作时刻 + D + 0.5
    （动作时刻与 D 都是策略自己发动作时的公开信息，合规）→ `add_completed`
  - `j ∈ executed ∧ j ∉ completed`：越界，`d > H − s_j` → `add_censored`
  - **零成本信息通道**：execute 反馈免费，review 通道关闭（第 5 步 no_review.md）。
- 任意时刻 `p̂(j) = α · d̂(family_j) + β`，d̂ 用更新后参数。
  估计量按杠杆选：均值（L1 打折用）或分位数（L2 守卫用）。

## 2. 杠杆 L1~L5：公式与防什么

### L1 打分（ATC，文献 1/45）

候选 j 的分数：

```
slack_j = due_j − (s_j + p̂_j)                    # 松弛时间，s_j = t + D + 0.5
score_j = (w_j / p̂_j) · exp(−max(slack_j, 0) / (κ · p̄))    # κ 默认 2.0
```

p̄ = 未执行作业的平均期望时长。ATC 在"急+短+重"三者间折中；
κ 是文献标准调参位（Vepsalainen & Morton 1987 建议 2~3）。
L1 关闭时退化为纯 WSPT（score = w/p̂），即 B2 同款打分。

**防的失败模式**：纯 WSPT 在 due 紧迫时可能先排一个长重活，把一票紧小活
拖过 deadline。ATC 的指数 tardiness 折中项专治这个。

### L2 截断防护（软罚项版，2026-11-23 修订）

初版为硬过滤放松链（q95→q75→均值→兜底），消融结果 **C2−C1 = −0.0047±0.0029
显著为负**——保守滤波在末段误伤候选；且硬守卫只作用在真实决策上，rollout
内部的贪心补完（greedy_complete）并不过滤，决策世界与模拟世界规则不一致。

修订为打分内软罚项，决策与模拟天然共用同一 scorer：

```
slack_j = due_j − (s_j + p̂_j)
score_j = (w_j/p̂_j) · exp(−max(slack_j,0)/(κ·p̄))           # L1 ATC
over_j  = s_j + q95(p̂_j) − H
若 over_j > 0: score_j *= exp(−over_j/(κ·p̄))               # L2 软罚项
```

越过程度以指数衰减进分数，"冒险值不值"交给 L4 rollout 用情景去权衡，
而不是一刀切过滤。

**防的失败模式**：L 族 σ=1.013，均值估计对长尾作业过于乐观；
不做防护时一个 60s+ 的长尾会吃掉大半时窗，后面一串作业全被 H 截断。

### L3 预算取舍（价值密度贪心）

剩余预算 `B_rem = B − cost` 装不下全部剩余作业的合法费用时，
候选按价值密度 `w_j / fee_j` 排序，只保留密度最高的那批（能装下几个留几个），
其余作业主动放弃（不执行就不花钱， weighted on-time 按总权重 W 归一，
放弃低权重作业是提高分子/分母比的合法手段）。

**防的失败模式**：贪心按分数排，可能把钱花在一个重但贵的远区作业上，
导致两个中等权重的近区作业没钱执行。L3 把预算约束从"事后撞墙"变"事前规划"。

### L4 rollout 前瞻（文献 39/40/41）

每个决策点：

```
候选 = 打分最高的前 m 个（默认 m=3，CRN 共用情景集）
对每个候选 c：
    对 K 个情景（默认 K=20，d 从更新后模型按族抽样，CRN：同序号情景跨候选复用）：
        内部快模拟：先执行 c，余程用"无 rollout 的同配置贪心"补完
    Q(c) = 平均加权准时率 − 大罚 × P(模拟中出现违规)
选 argmax Q，全部并列退化回 L1 最高分
```

内部快模拟 `simulate_remainder` 逐字节复刻 `Trial.execute` 的语义
（s=t+D+0.5，p=αd+β，C=s+p，费用式，next_avail=s+max(p,b)，
H 截断=未完成，预算/H/动作数约束违规=中止重罚），但不产生副作用。
**防的失败模式**：myopic 高分作业堵门——一个当下分数最高的作业会把设备
占到大尾巴，使后面高价值作业错过 due；一步前瞻用 K 个情景把这条因果链
显性化。Bertsekas & Castañón 1999 的告诫钉在这：rollout 上界=基策略质量，
所以消融必须先单验 L1~L3（第 7 步解读顺序由此定）。

### L5 离线局部搜索（先验序列改进，文献 46 的局部搜索子集）

reset 时：

```
初解 = 期望时长确定性扫描（ATC 打分 + 合法性与预算守卫，mean p̂）
循环直到无改进或达步数上限：
    邻域 = 相邻交换 ∪ 前插（移除一个作业插到前面某个位置）
    评价 = G 个情景（默认 G=10）下的固定序列期望加权准时率
    接受第一个改进邻居（first-improvement，省算力）
在线效果：L5 开 → 候选打分改用序列位置序（越早位置分越高，ATC 只做并列打破）
```

**防的失败模式**：myopic 在线规则对"释放时间造成的结构性冲突"失明——
两个紧 due 作业若被同一个中间作业隔开，ATC 每步都是局部最优但全局次优。
离线搜索把整条约 12 作业的序列当对象整体优化。确定性验证：固定 seed
两次 reset 输出同一序列。

## 3. 基线梯度（第 7 步对手）

| 基线 | 规则 | 定位 |
|---|---|---|
| B1 EDD | 候选中 due 最小先服务 | 规则派地板；1‖Lmax 确定最优解的经典规则 |
| B2 WSPT-mean | w/p̂，p̂=α·mean+β | 确定性等价标准解；1‖ΣwC 确定最优规则 |
| B2b WSPT-median | w/p̂，p̂=α·median+β | A2 对照臂：中位数 vs 均值单独成实验问题 |
| B3 WSPT-q90 | w/p̂，p̂=α·q90+β | 稳健派最强朴素形态；用它分离"分布感知"与"前瞻"的贡献 |

三个基线都给预算/H 合法性预检（代表"规则做对了"的版本，不送 INVALID），
但**不给** L2 随机守卫、L3 取舍、L4 前瞻、L5 序列、更新器。
公平性说明：基线的 fee 检查只防"必撞墙"的合法性问题，不防"可能撞墙"的
随机风险——后者正是我们杠杆的价值空间。

## 6. SAA 最优性间隙（saa_gap.py，文献 40/41）

回答"距最优多远"，把竞赛文升格成论文级：

```
最大化问题：v* = 最优期望加权准时率
下界：M 批 × N 情景 SAA 子问题的解值 v_m，LB = mean(v_m) − 1.96·sd/√M
上界：任一可行解（我们 C6 的先验序列）在大样本独立情景集上的评价值 UB
间隙 gap = UB − LB ≥ 0；gap/UB 即"离天花板相对距离"
```

S1 只有 8 作业：SAA 子问题用**精确枚举**全部前序可行序列（真下界）。
S2/S3 枚举不可行：局部搜索解 SAA 子问题，此时 LB 是"启发式内最好"，
间隙解读带上界含义的 caveat，写进第 7 步报告。
注意口径：SAA 度量的是"固定先验序列策略类"，我们的在线 recourse 策略
弱占优于该类（recourse 只会更好），所以间隙证书对我们策略是保守的。

## 7. 自检清单（test_strategy.py → q6_strategy_checks.json）

1. **合法性**：C6 在 3 案例 × 3 种子（validation split）上 invalid_actions 恒 0
2. **回放一致**：同 (case, seed, config) 双跑，动作日志逐字节一致（CRN 地基）
3. **放松链不空**：构造 s 近 H 的合成 snapshot，q95 全灭时仍返回合法动作
4. **引擎退化**：C0 与 B2 在同样本上逐决策动作一致（证明引擎关掉杠杆=基线）
5. **离线确定性**：L5 双 reset 同 seed 输出同一序列
6. **L5 单调不劣**：固定情景集上，局部搜索后序列期望得分 ≥ 初解
7. **SAA 间隙冒烟**：S1 小配置（M=5, N=10）跑通，gap ≥ 0 且量级合理

## 8. 修订记录（2026-11-23，第 7 步结果驱动的第二轮设计）

- **A1**：L2 硬过滤放松链 → 打分内软罚项。依据：C2−C1=−0.0047±0.0029 显著为负，
  且硬守卫导致决策世界与 rollout 模拟世界规则不一致。罚项进 scorer 后两者天然一致。
- **A2**：打分/扫描的默认点估计均值 → 中位数。依据：B3−B2=−0.0049±0.0020 显著为负
  （高估有害）；对数正态右偏下中位数更稳健。配套新增 B2b WSPT-median 基线臂，
  使"A2 前提"本身接受显著性检验。κ 因打分函数改变重选：2.0 → **3.0**（K=40 不变）。
- **A3（映射感知放松链）：否决**。守卫已含 α；α=1.5 映射优势归零的机制是问题整体
  变难而非策略漏洞，加映射专属旋钮=按验证集调映射，违反冻结纪律。处置：写入论文
  "模型评价—缺点"章作为鲁棒性边界与后续方向。
- **L5 评价一致性修复**：初解与邻居必须在同一批情景上评价（此前跨情景集比较把
  抽样噪声当改进信号，自检 6 抓到）。修复后离线搜索增益从 +1.7 个点升到 +11 个点
  （固定情景集口径）。
- **性能**：_z(0.95) 打分热路径惰性缓存（曾致整体慢 5 倍）。
