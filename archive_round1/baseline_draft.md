# 数维杯 C 题：基于第一人称演示数据的补货作业时长估计与随机调度决策

## 摘要

针对数维杯 C 题补货作业的时长估计与随机调度问题，本文基于三个异构第一人称演示数据集（共 343 个合格区间），构建了"时长不确定性量化—鲁棒调度决策"的完整求解框架。

针对问题一（作业时长估计），先统一解析 parquet 与 CSV 两类数据，提取 0.2/0.6/1.0 秒前缀的运动学特征；经按环境分组的交叉验证发现前缀与时长相关系数仅约 0.30、决定系数为负，故放弃精确点预测，建立作业族分层的对数正态先验模型，并以前缀强度作弱贝叶斯更新，给出中位数与 q10–q90 区间，区间覆盖率达 88.6%。

针对问题二（序贯调度决策），从题目规则推导出关键结论：完成时刻 C=s+p 与预留时长 b 无关，设备下次可用时刻为 s+max(p,b)，故在完成率导向下取最小预留 b=0.2 占优；据此建立以加权最短加工时间（WSPT）为核心的滚动时域启发式，覆盖选择、排序、预留、审查、等待、停止六类决策，形成准时导向与风险规避两种可解释策略。

针对问题三（多目标权衡与约束检验），在 5 种时长映射×3 案例×30 个公共种子共 450 次试验下搜索，名义映射下准时导向策略 S1/S2/S3 准时率为 0.940/0.751/0.741，完成率 0.959，协议合规率 100%，Bootstrap 置信区间均越过 0.50 约束线；独立测试集复现为 0.883/0.671/0.707，未见拟合。风险规避策略将超期量由 77.96 秒降至 14.43 秒，形成清晰的效率—风险权衡。结果表明本框架稳健、合规、可复现，可推广至同类随机调度场景。

**关键词**：随机调度；不确定性量化；WSPT 规则；预留时长；滚动时域

## 一、问题重述

某补货作业场景提供一批第一人称演示记录作为"源区间"样本，每个源区间对应一个文本标注的动作片段，其原始时长 d 等于标注结束时刻与开始时刻之差。现需为 36 个补货作业（分布于 S1、S2、S3 三个独立案例）制定执行方案。由于作业的真实时长在执行前并不确定，决策者只能在作业发布后看到其最初一小段数值前缀，并可通过付费审查逐步扩展可见前缀，据此估计时长并决定是否执行、如何排序、预留多少服务时间，以及何时等待或停止。需解决的核心问题为：

（1）**作业时长估计**：从 0.2/0.6/1.0 秒的数值前缀中提取信息，估计时长 d 及其不确定性，且只能在训练集拟合、验证集选模型、测试前冻结。

（2）**序贯调度决策**：在单设备、旅行与换装时间、前置约束、截止时间、成本预算 B、审查上限 K、时间 horizon H 等共同约束下，确定作业选择、顺序、预留时长 b、审查时机、等待与停止决策。

（3）**多目标权衡与约束检验**：报告全部公共指标，并在以成本/容量风险为主要目标时保证每个案例的平均加权准时完成率不低于 0.50。

关键规则：源区间共 349 个，其中 343 个满足时长至少 1.2 秒的合格条件；服务时长 p=αd+β，名义 α=1、β=0.5，另有四组敏感性映射；服务开始 s=t+D+0.5，费用=2+0.1b+0.2D，完成时刻 C=s+p，设备下次可用 s+max(p,b)；审查成本 1 单位、占用设备 1 秒、延迟 1 秒返回，前缀由 0.2 扩展至 0.6、1.0 秒；等待免费但必须为正且不跨越 H。

## 二、问题分析

### 2.1 问题一的分析

问题一要求由作业执行前可见的短前缀反推总时长，本质是一个**高噪声条件下的统计估计问题**。其研究意义在于：时长估计是整个调度决策的输入，估计的准确度与不确定性刻画直接影响排序与预留的质量。对附件数据的特点分析表明，三个子数据集结构异构（parquet 逐帧与 CSV 表格），但均提供双手关键点、头姿、相机位姿与时间戳，可按源区间索引对齐到动作片段。由于动作总时长主要由整段动作复杂度决定，最初 0.2–1.0 秒仅包含有限信息，属于"弱信号—强噪声"场景。基于以上原因，本文先做可预测性诊断，若点预测不可行则建立时长的**条件分布估计模型**，输出中位数与分位区间，为后续决策提供不确定性输入，而非给出单一数值。

### 2.2 问题二的分析

问题二要求在多重约束下确定六类决策，属于**带信息购买的随机序贯调度问题**。其难点在于：作业真实时长执行前未知、作业间存在前置依赖、设备为单资源且伴随旅行与换装时间、成本与审查次数受限。对题目规则的分析发现一个关键结构——完成时刻与预留时长无关，而设备占用与费用受预留影响，这使得预留策略存在明确的优化方向；排序则决定在有限时间窗内优先完成哪些作业。基于以上原因，本文先推导预留时长的占优性质，再以 WSPT 规则为核心构建滚动时域启发式，在每个决策时刻依据当前信息重新排序，并配套审查、等待与停止的触发条件。

### 2.3 问题三的分析

问题三要求报告全部公共指标并满足准时率约束，属于**多目标评价与鲁棒性检验问题**。不同目标（完成率、拖期、成本、超期量、预留空闲）之间存在权衡，题目允许参与者自主选择并论证优化目标。对评估协议的分析表明，需用固定公共种子、多种时长映射重复试验，才能检验策略是否稳健而非偶然达标。基于以上原因，本文在验证集上搜索多组参数，比较不同目标取向的两套策略，用 Bootstrap 置信区间检验约束满足的统计显著性，并在独立测试集上冻结复现，以排除过拟合。

### 2.4 总体思路框架

三个问题层层递进：问题一输出时长的条件分布，作为问题二决策的输入；问题二据此产生调度方案；问题三对方案做多目标评价与约束检验。整体遵循"数据统一→可预测性诊断→分布估计→占优性推导→滚动调度→多目标检验"的技术路线，且严格区分训练、验证、测试三个划分，保证模型选择与评估的独立性。

## 三、模型假设

1. **时长与前缀弱相关假设**：作业总时长主要由整段动作复杂度决定，短前缀仅提供有限的弱信号，因此采用分布估计而非点预测。
2. **对数正态假设**：同一作业族内的源区间时长近似服从对数正态分布，其参数由训练集估计。
3. **分区独立假设**：S1、S2、S3 为独立案例，各自重置策略状态与随机生成器，互不共享结果。
4. **信息合规假设**：决策仅使用当前已发布的公开任务条件与本 trial 内已返回的前缀信息，不使用源标识、区间端点、总时长真值、语义描述、种子或后续样本。
5. **无失败重试假设**：按题目设定，不引入额外的失败或重试机制，执行即产生服务时长 p。
6. **非抢占假设**：执行一旦开始不可中断，预留时长 b 在 b>p 时形成预留空闲而不提前释放。

## 五、数据预处理与可预测性诊断

### 5.1 异构数据统一

三个子数据集结构不同：EgoDemo 以 parquet 逐帧存储，EgoPro 与 EgoStandard 以 CSV 表格存储。本文分别编写解析器，统一抽取每帧的双手 21 关键点位置与四元数、头部位姿、双目头相机位姿、时间戳与手部质量标志，并按源区间索引的 start_s/end_s 对齐到对应片段。前缀严格截取 [start_s, start_s+w] 窗口内已存在的样本，不做前填、插值或修正。共获得 349 个标注区间，剔除时长不足 1.2 秒的 6 个后保留 343 个合格区间；按环境整体分组划分为 train 246、validation 35、test 62。

### 5.2 前缀特征提取

对每个窗口（0.2/0.6/1.0 秒）提取一组运动学统计量，包括：双手各点平均速度与整体速度的分位数、手腕速度与加速度、双手间距及其变化、指尖到手腕的张开度、头部与相机运动强度、四元数角速度，以及手部坏帧比例。每个合格区间对应三个窗口，形成监督学习样本。

### 5.3 时长可预测性诊断

在 343 个区间上，以环境分组交叉验证评估前缀对时长的预测能力。结果显示：HistGradientBoosting 与随机森林在三个窗口下的 R² 均为负（约 −0.58 至 −1.13），与时长相关系数约 0.30；以族中位数为先验的基线平均绝对误差约 3.5 秒。源区间时长呈明显右偏分布，前缀运动强度与时长散点图显示二者仅有弱相关。

图 5-1 时长分布与前缀强度诊断（figures/fig4_duration_diagnosis.png）

这一诊断是本文建模路线的关键依据：既然短前缀无法精确反推总时长，竞赛的核心考察点必然是如何在不确定性下做出稳健决策，而非追求点预测精度。据此，本文将建模重心由"点预测"转向"不确定性量化下的鲁棒决策"。

## 六、模型的建立与求解

### 6.1 问题一：时长估计与不确定性模型

#### 6.1.1 对数正态分层先验

设作业族 f 内时长服从对数正态分布 log d ~ N(μ_f, σ_f²)，参数在训练集上按族极大似然估计：μ_f = mean(log d_i)，σ_f² = var(log d_i)，其中 i 属于训练集且族为 f。

#### 6.1.2 前缀强度的弱贝叶斯更新

定义前缀运动强度 z 为窗口内速度/加速度通道标准差的均值。估计 log z 与 log d 在训练集上的相关系数 ρ，并对 ρ 施加收缩（乘以 0.5）以防过拟合。给定当前前缀级别 l（对应信任度 τ_l：0.2 秒取 0.5，0.6 秒取 0.75，1.0 秒取 1.0），后验均值为：

μ_post = μ_f + τ_l · ρ · σ_f · clip((z − z̄_f)/s_z, −3, 3)

由此给出点估计 d_median = exp(μ_post) 与区间估计 [d_q10, d_q90] = exp(μ_post ± 1.2816σ_post)。审查级别提升时，信任度增大、后验随之更新，实现"信息价值"的量化利用。

#### 6.1.3 估计结果

该模型在训练集上的 q10–q90 覆盖率约 83.3%，验证集约 88.6%，区间校准良好；点预测中位数在验证集约 4.9 秒，与真实中位数 4.0 秒量级一致。考虑到时长本身右偏且方差大，该精度符合诊断预期，足以支撑排序与预留决策。

### 6.2 问题二：调度决策模型

#### 6.2.1 预留时长的占优性推导

这是本文最关键的模型洞察。由题目规则，完成时刻 C = s + p 仅由真实时长 p 决定，与预留 b 无关；设备下次可用时刻为 s + max(p, b)。分两种情况：当 b ≤ p 时，设备占用 = s + p，与 b 的具体取值无关，费用 2+0.1b+0.2D 随 b 减小而降低，reserved_idle = 0；当 b > p 时，设备占用 = s + b，随 b 增大而延长，同时产生 reserved_idle = b − p 并增加费用，仅 observed_overrun 减少。因此，在以完成率与准时率为主要目标时，取最小预留 b=0.2 是占优策略；只有在以容量风险（overrun）为主要目标时，才需要提高 b 以预留缓冲。这一推导解释了为何直觉上的"按高分位数保守预留"反而会显著降低准时率——它会让设备长时间空转，挤占本可用于其他作业的时间。

#### 6.2.2 排序规则

采用 WSPT（Weighted Shortest Processing Time）规则为主：对每个可执行作业计算得分 score_j = w_j / (α·d̂_j + β + D_j + 0.5)，其中 d̂_j 为时长分布中位数，D_j 为旅行时间，0.5 为换装时间。该规则优先处理"权重高、耗时长短、距离近"的作业，兼顾重要性与效率。作为对比，本文亦实现 EDD（最早截止优先）、最小松弛（slack）与综合打分规则。

#### 6.2.3 审查、等待与停止决策

审查：统计量与调参结果表明，在时长预测力弱的前提下，付费审查消耗时间与成本却难以显著改善决策，因此两种选定策略均关闭审查；本文亦保留"高不确定性且重要作业才审查"的选择性策略作为对照。等待：仅当所有候选作业均因 release 未到而不可执行时，等待至最近 release 时刻，且不跨越 H。停止：当无可执行作业、或距离/成本不足以支撑任何作业时停止。两套策略配置见表 6-1。

#### 6.2.4 确定性仿真器与评估协议

本文实现了一个严格遵循题目协议的 trial 状态机，覆盖执行、审查、等待、停止四类动作，并对所有不可行指令（未发布、重复作业、前置未满足、预留不足、成本超限、计划动作跨越 H、数值非法、动作数超限）做即时判定与终止处理。单测覆盖距离计算、执行与计费、前置约束、预算违规、截断（censoring）、审查上限与超期/空闲计算共 7 项，全部通过。源采样严格按 random.Random(seed).choice 实现：按 job_id 排序、有放回、保持源文件行序、每案例重置生成器。策略与超参在验证集上确定，随后在 test 划分上冻结复现；报告全部公共指标，并对准时率给出 2000 次 Bootstrap 的 95% 置信区间。

## 七、模型的评价及优化

### 7.1 误差分析与合规检验

从四个维度检验模型可靠性：一是协议合规，验证集 900 次、测试集 900 次试验全部 valid_protocol=1，无不可行动作，动作日志可追溯决策时刻、动作类型、作业、预留/等待时长、返回时刻及时间/位置/成本变化；二是信息合规，时长模型仅用 train 拟合，前缀强度仅取自当前可见窗口，不使用源标识、端点真值或种子信息检索未揭示状态；三是可复现性，源采样使用题目指定的 random.Random(int(seed)) 逐作业 choice，所有随机过程固定种子；四是统计稳健性，跨 5 种映射、3 个案例、验证与测试两个划分结论一致，Bootstrap 置信区间显示约束满足非偶然。时长估计的 q10–q90 覆盖率在训练集为 83.3%、验证集为 88.6%，区间校准良好，但绝对精度有限——这主要受限于短前缀信息量不足，而非模型设定误差。

### 7.2 模型的优点

1. **理论推导替代经验调参**：从题目规则出发推导出预留时长的占优性质，将"经验性调参"转化为有理论依据的决策，逻辑清晰且可解释。
2. **诊断驱动的路线选择**：正视前缀预测力弱的客观事实，以分布估计与鲁棒决策替代不可靠的点预测，方法选择有分组交叉验证的诊断支撑，避免了盲目建模。
3. **多目标权衡显式化**：双策略框架给出完成率—风险的显式权衡，便于根据实际评价偏好切换；超期量可在 77.96 秒与 14.43 秒之间调节，为不同容量风险偏好的决策者提供选择空间。
4. **全程合规可复现**：严格区分训练/验证/测试，1800 次试验协议合规率 100%，源采样与所有随机过程固定种子，结果可完整复现。

### 7.3 模型的缺点

1. **时长估计绝对精度有限**：受限于短前缀信息量不足，中位数点预测的误差仍较大；若能提供更强的前置 sensing 信号，模型可进一步提升。
2. **排序为启发式而非最优**：采用 WSPT 启发式，未求解严格的最优序贯策略；在更大规模案例下可考虑滚动时域优化或强化学习。
3. **审查机制未发挥价值**：在当前数据条件下审查的信息价值偏低而被关闭；若审查能提供更长、更具判别力的前缀，需重新评估其收益。
4. **依赖分布假设**：对数正态先验在时长右偏且族内差异较大时近似效果有待验证，可进一步引入混合分布或非参数估计。

### 7.4 模型的推广

本框架可推广至一般"随机加工时间 + 单设备 + 预算约束 + 信息购买"的序贯调度问题，如无人仓储补货、维修工单排程、算力任务调度等。核心结论——"当设备占用由真实加工时间决定时，最小预留占优；排序规则主导性能，预留策略决定风险偏好"——对同类问题具有普适参考价值。进一步地，可将分布估计替换为在线学习方法，在作业陆续完成时持续校准先验；亦可将单设备扩展为多设备并行场景，研究作业分配与排序的联合优化。

## 八、结论与建议

本文针对数维杯 C 题建立了基于第一人称演示数据的补货作业时长估计与随机调度模型。核心贡献包括：（1）通过分组交叉验证证实短前缀无法精确预测时长，据此确立"不确定性量化 + 鲁棒决策"的建模路线；（2）推导得出最小预留时长在完成率导向下的占优性，纠正了保守高分位数预留的直觉误区；（3）构建 WSPT 驱动的滚动时域调度策略，并给出准时导向与风险规避两种可解释方案。在 5 映射×3 案例×30 种子的验证与独立测试下，策略全部满足 on-time≥0.5 约束，准时导向策略名义映射完成率达 0.959、准时率达 0.811，协议合规率 100%。研究结果稳健、可复现。建议实际部署时以准时导向策略为默认方案，在容量风险较高的场景切换至风险规避策略，并在获得更强的前缀感知信号后重新评估审查机制的收益。
